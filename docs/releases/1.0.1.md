## What’s new

- Start focus sessions when you’re ready with the new Start Focus button.
- Choose focus sessions from 1 to 120 minutes.
- Improved focus and break timers when returning to the app.
- More reliable reminder settings and recovery from notification errors.
- Improved saved-history recovery, streak calculations, and smaller-screen layouts.

## TestFlight testing notes

Set Focus Time to 1 minute in Settings, return Home, and tap Start Focus.
Confirm that the countdown starts, then opens Break Time when it expires.
With notifications enabled, also check the reminder while the app is in the
background. Take, cancel, or skip a break and verify that Home waits for the
next Start Focus tap. Check that settings and break history survive relaunch.
